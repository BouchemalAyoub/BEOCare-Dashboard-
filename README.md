# 💊 BEOCare - Pharmaceutical Distribution Dashboard

## 📖 Overview

BEOCare is a fictional pharmaceutical distribution company created for this Business Intelligence project.

This interactive dashboard was developed using **Microsoft Power BI** to analyze sales performance, products, customers, and medical representatives through dynamic visualizations and KPIs.

> ⚠️ **Disclaimer**
>
> - **BEOCare** is a fictional company created solely for educational purposes.
> - The dataset used in this project is also fictional and was generated with the assistance of Claude AI to simulate a realistic business environment.
> - This is my **first Power BI dashboard**, developed as part of my learning journey in Business Intelligence and Data Analytics.

---

## 🎯 Project Objectives

- Analyze sales performance
- Monitor key business indicators (KPIs)
- Evaluate product performance
- Analyze customer behavior
- Compare sales representatives' performance
- Support business decision-making through data visualization
